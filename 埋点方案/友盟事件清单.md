# 友盟事件清单

状态：current

## 统一参数口径

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| page | 当前页面语义 | `vip_page`、`candy_page`、`mine` |
| source | 行为来源，必须使用固定枚举 | `mine`、`vip_page`、`candy_page`、`inner_os_unlock` |
| entrance | 入口来源，默认与 source 保持一致 | `mine`、`chat_quick_candy`、`image_access` |
| popup_type | 弹窗类型 | `membership_guide`、`feature_limit`、`recharge_result` |
| product_id | 业务商品 ID | `week`、`month_auto_first`、`candy_800` |
| product_name | 商品展示名 | `周卡`、`800糖果` |
| product_type | 商品类型 | `week`、`month`、`year`、`lifetime`、`candy` |
| price | 售价 | `18.0` |
| pay_type | 支付方式 | Android `alipay`，iOS `apple_iap` |
| result | 结果 | `success`、`fail`、`cancel`、`timeout` |
| fail_reason | 失败/取消原因 | `用户取消`、`创建订单失败` |
| is_first_recharge | 是否首充 | `true`、`false` |
| is_vip | 公共参数，当前会员态 | `true`、`false` |
| position | 点击位置 | `membership_hero`、`profile_menu`、`0` |
| button_name | 按钮语义 | `buy_now`、`restore_purchase` |

## 固定来源枚举

| source / entrance | 使用场景 |
| --- | --- |
| `mine` | 我的页入口进入会员页/糖果页 |
| `vip_page` | 会员页内套餐、协议、购买等行为 |
| `candy_page` | 糖果钱包/充值页内档位、购买等行为 |
| `chat_quick_candy` | 聊天页纯快捷充值入口 |
| `send_message_insufficient_candy` | 发消息糖果不足触发的充值/会员引导 |
| `inner_os_unlock` | 解锁内心 OS 糖果不足触发的充值/会员引导 |
| `image_access` | 查看/生成图片糖果不足触发的充值/会员引导 |
